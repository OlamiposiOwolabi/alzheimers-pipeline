# Alzheimer's Disease Drug Discovery Pipeline

## Overview
A computational pipeline for Alzheimer's disease drug discovery using 
multi-omics integration and drug repurposing approaches.

## Pipeline Stages
1. Data ingestion & preprocessing
2. Multi-omics integration
3. Differential expression analysis
4. Drug repurposing screen
5. Machine learning & candidate prioritization
6. Visualization & reporting

## Tech Stack
- Python 3.10+ (pandas, numpy, scikit-learn, rdkit)
- R 4.6.0 (limma, DESeq2, edgeR, clusterProfiler)
- Git for version control

## Project Structure
- data/        → raw and processed omics data
- scripts/     → Python and R analysis scripts
- notebooks/   → Jupyter exploratory notebooks
- results/     → pipeline outputs and figures
- models/      → trained ML models
- docs/        → references and methods
